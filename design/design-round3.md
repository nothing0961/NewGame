# 设计备忘 · 第三轮：层间流程骨架＋层内关卡结构（2026-10-05）

> 会话决策记录。本轮范围：「战斗之外」的第一块——八层推进的呈现（层地图页）、层与层过渡（上行过渡页）、层内结构（战斗关／事件关）、第一层→第二层衔接（可玩占位）。
> 状态图例同 `setting/README.md`。第二层及以后的具体内容全部为【测试内容】占位，随各层设计轮替换。

## 0. 决案汇总（用户定，两轮问答）

1. **层推进呈现 ＝ 独立层地图页**（非纯线性文字推进）
2. **层间过渡 ＝ 生成过渡插画**（Maker 生图，非程序化底）
3. **层内结构 ＝ 多个小关卡**（战斗关＋事件关混排，层主战收尾）
4. **第一层→第二层衔接 ＝ 第二层可玩占位**（骨架端到端跑通，内容全占位）
5. **事件关 ＝ 玩法型事件**：事件页＝可注入小玩法的容器；首版做最小占位壳验证链路，真实小玩法待专轮设计
6. **地图职能 ＝ 层粒度＋展开当前层关卡**：八层竖向＋当前层展开关卡节点（图标/进度）
7. **死亡规则 ＝ 本轮实现＋教程同步**：战斗失败（生命归零）→回该层第一关；教程战不再免死（法阵拽回退役）

## 1. 层循环总结构

层＝关卡序列，层主战＝层的最后一关：

```
进入层 → 关卡 1 → 关卡 2 → …… → 层主战（净化的唯一发生点）
      → 净化 → 收下罪卡 → 层主同行 → 上行过渡（插画页＋同行读白）→ 层地图（下一层点亮）→ ……
```

- 关卡类型（骨架至少两种，可扩展）：
  - **战斗关**：两类形态——小怪战（胜利→直接回层序列，无净化/收下）与层主战（胜利→净化→收下→同行）
  - **事件关**：玩法型事件，见 §4
- 教程层（第一层）＝该循环的特化：保留现有编排（召唤告知→菜单→教学→练习站→转化→层主战→净化→收下→三问→同行）；只接入死亡规则；教程段是否整体关卡化【待定】
  - 三问＝教程层特有节拍（情绪验证装置）；第二层起 净化→收下→同行 直接衔接
- 层 1 罪卡命名清账（现「暴怒」实为懒惰层收下物）维持 open-decisions 清账项，待文本定稿轮

## 2. 层地图页

- 形态：八层竖向排布（第 8 层在顶、第 1 层在底——向上爬）；三态：
  - 已过层：点亮＋「已净化」
  - 当前层：高亮可点 → 展开该层关卡节点（类型图标：战斗/事件；状态：已完成/当前/未到）→ 点当前节点进入/继续（**修订·第四轮**：展开形态＝分支路线图，见 `design-round4.md`）
  - 未解锁层：暗色＋锁定；点击提示「待续」
- 教程结束（三问→同行结尾后）首次出现（层 1 已过、层 2 当前）；层 2 完成→地图停在「第三层·待续」（demo 边界）
- 入口：教程完成后菜单「继续剧情」→ 地图页；地图页提供「进入练习站」「返回菜单」入口
- 实现形态：程序化绘制（无正式美术）；正式视觉属美术轮

## 3. 上行过渡页

- 形态：过渡插画底图＋读白区（同行层主对话）＋「继续」按钮 → 层地图
- 插画：Maker 生成 **1 张通用「上行」意象**（无文字），跨层复用，后续按需按层补／美术轮替换；运行时资源存 `assets/sprites/ui/`（进提交清单）
- 首次出现：教程结束（三问后）；文本＝【测试内容】占位

## 4. 事件关（玩法型）

- 事件页＝容器：标题＋场景说明＋**玩法区**（宿主，可注入小玩法模块）＋完成按钮
- 首版占位壳：玩法区放一个最小交互（三选一占位：选一个→就地显示占位反馈→可完成）——验证「进入→交互→完成→回层序列」链路
- 真实小玩法（机关/挑战/迷你机制）待专轮设计；第二层占位事件内容全标【测试内容】

## 5. 死亡规则（实现）

- 战斗失败（玩家生命归零）＝判负：**法阵拽回退役**（全战斗）
- 失败 → 回「对应层级的第一关」重开（层内进度重置）
  - 教程层（提案待复核）：教程战失败回教程层首段（召唤告知）＝按规则字面执行；备选＝回「转化」段（跳过序章引读）
  - 练习站（提案）：练习战失败＝练习结束（回练习站，无惩罚）——训练场不参与死亡规则
- 战斗内呈现：败北层＋「重新开始本层」按钮 → 层首

## 6. 罪卡接线（收下→牌组）

- 收下的罪卡从战斗态提出到**局内收藏**（`RunState`），战斗结束即入仓库（`CardPool.owned`）
- 练习站仓库：改按 `owned` 动态显示（含已收罪卡）；组卡**最多放一张罪卡**（七选一约束的最小实现；未收的罪卡不出现）
- 战斗内封印/解锁泛化：按「牌组中的罪卡」逐卡检定（任务/保底参数按卡配置）；教程战照旧
- 存档不在本轮（内存态；属元进程闭环）

## 7. 第二层可玩占位（本轮验收范围）

- 第二层＝色欲层（阿斯莫德）；关卡序列占位：
  1. 事件关（占位壳）——开场遭遇
  2. 战斗关（小怪）——占位敌人「污染体」（数值占位）
  3. 事件关（占位壳）——混排展示
  4. 层主战——阿斯莫德（占位数值/卡组）→ 净化 → 收下色欲占位罪卡 → 同行
- 第二层完成 → 上行过渡 → 地图（层 3 锁定「待续」）
- **全部文本/数值/卡数据＝【测试内容】占位**，第二层设计轮整体替换
