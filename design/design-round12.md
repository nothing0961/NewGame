## 3. 笔筒污染体遭遇战（`Mode.AMBUSH`）

真实战斗（用户定 1），照教学战模式：钉死牌组、不洗牌、不检定罪卡。

| 参数 | 值 | 说明 |
|---|---|---|
| 敌名／血量 | 笔筒污染体 / **10** | T1 强攻上限 9（三魔弹＋强欲魔弹＝6 单位）留一口气 → T2 补刀，呼应「僵直→欲望魔弹」 |
| 敌方牌组 | `{enemy_strike: 6}` | 每回合**钉死至多 1 张**（同教学战；附「戳击」2 伤）；不出「它/她」占上风读白 |
| 钉死牌组（摸牌序） | `guard→strike→strike→strike→greed_shot→guard→strike→strike` | 开局手＝防御＋魔弹×3＋强欲魔弹 |
| 体系 | Cost 6・HP 20・摸牌 3・手牌上限 8・90 秒 | 上限 8＝5+3 水位不触发强制弃牌（教学同款口径） |
| 胜利 | 全灭→`_end_ambush()`（ENDED＋TEXT_AMBUSH_WIN），不进 STRIP、无收藏 | |
| 失败 | 判负覆盖层（读白＝教学版「站起来，再来一次」）→ 按钮「再来一次」→ **原地重开本战**（不重看入场演出） | |

胜利回 `_show_l2_entry_after()`（ENTRY_B）；`_battle_context == "ambush"` 分支。

## 4. 流程接线（`main_flow`）

```
教程主战胜利 → ACT2_BEATS（既有）→ [新] _show_l2_entry()
  ENTRY_A → 迎战 → AMBUSH 战斗 ─胜→ ENTRY_B → l2_entry_done=true・落盘 → _open_map()（L2 地图）
                                └败→ 原地重开 AMBUSH（回卷点＝战斗前，不重看 A）
L2 地图 → 层主战节点确认 → [新] intro 演出 L2_BOSS_INTRO → 迎战 → 阿斯莫德层主战（既有）
```

- **门控键 `l2_entry_done`**（RunState/SaveGame，旧档缺键＝false）：`_ready` 路由
  ——`act2_done` 已看且 `l2_entry_done` 未看**且 current_layer==2 且 column_index==0** → 补看入场；
  老档已进 L2 中段/更深层（column_index>0 或 current_layer>2）→ 直接进地图（不补，避免错位重演）。
- `_ready` 路由改为：`tutorial_done` → `act2_done?` →（entry 门控）→ `_open_map()`。
