# 世界框架

## 一句话

主角被「懒惰」召唤到被七宗罪异化的平行世界；她从最底层出发逐层向上，击败七宗罪、收集力能，最后要面对这个世界的自己。

## 核心立意

**核心主题：「涌现」【用户定 2026-10-04】**——奇迹的涌现：一群动机各异、甚至互相矛盾的个体彼此碰撞、纠缠，抵达临界点之后，自发诞生出谁都没有预先设想的全新结果（小组扩写稿表述）

**机制即主题：收下的罪永久留在牌组 ＝ 被消化的痛成为自己的一部分（「牌组就是你」）。**

- 数字原型已实现该机制：罪卡 `permanent = true`，打出后进入 `collection` 不再离开

## 主框架【正典·用户口述 2026-10-02】

- 主角（贝嘉）被懒惰召唤到平行世界
- 世界被七宗罪异化
- 异化源头 ＝ 这个世界的主角（boss，贝嘉的异世界同位体）身上的七宗罪权能
- 懒惰在异化之前召唤了她 → 由此分化 boss 权能、削弱 boss
- 主线 ＝ 击败七宗罪、收集力能 → 最后面对这个世界的自己

## 出牌区与回合节拍【正典·用户口述 2026-10-03】

- 屏幕底端 ＝ 手牌区：手牌上限 **7 张【2026-10-07 数值紧缩制：8→7（教学战豁免＝8）；历史：用户改定 2026-10-03·续 13，原 13】**——牌组扩到 10 张后超限行为可达（每轮摸 4 把手牌顶过上限）；超出上限强制跳出弃牌页，从手中选牌弃掉直到回到上限；获得牌＝下一节「获得牌与敌人手牌」
- 第二块区域 ＝ 出牌区：从手牌选牌摆放，最多 4 张【2026-10-07 紧缩制：5→4】；**摆放不生效、不扣 Cost**；已摆的牌可一一收回，重新选择要打出的牌
- 「打出」＝统一结算整批：扣掉这批合计 Cost、依次生效；收回重摆后再打出，同样只按最终这一批结算一次
- **打出即结束回合【用户改定 2026-10-03】**：按「打出」结算整批后本回合立即结束——战斗未结束时自动轮到敌人回合、随后进入新的玩家回合（曾为「一回合只打一批，然后手动结束」，已废）；4 卡槽 ＝ 每回合出牌数上限【2026-10-07 紧缩制：5→4】；剩余 Cost 作废（新回合重置满）
- 回合结束三路径同一结算：按「打出」（有摆放时）／手动「结束回合」（有摆放走打出同路径，无摆放直接过回合）／**45 秒**到时自动——都先结算出牌区再结束，此后自动敌人回合 → 新玩家回合
- 手牌打空不再自动过回合（旧规则废除；需求如常，手动结束）
- 原型实现：`BattleState.staged` 出牌区 ＋ `stage_card` / `recall_card` / `commit_staged`（结算整批后自动 `_enemy_turn()` ＋ `_start_player_turn()`；`batch_committed` 保留作结算窗口防重入）；`end_turn` 有摆放时直接走 `commit_staged()`；`gain_card` / `needs_discard` / `discard_from_hand`；`battle.tscn` 手牌滚动区（上限 7；教学战 8）＋ `%PlayBox` 4 卡槽（均为 2026-10-07 紧缩制后值） ＋ `%CommitButton`（显示合计 Cost 预告）＋ `%TurnTimerLabel`（剩余秒数）；练习战同一套规则；引擎级测试覆盖「出牌区 → 手牌」拖回路径（2026-10-03 补）

## 罪卡规则（七宗核心卡）【正典·用户口述 2026-10-04】

- 七宗罪 ＝ 七张核心卡（罪卡）；**组卡时七选一**——玩家只能把其中一张放进牌组
- **仅净化获得**：不收下罪卡就永远拿不到它（练习站仓库不含罪卡）
- 每张罪卡 **Cost 均为 6**
- **解锁条件（双轨，满足其一即可用）**：完成牌面任务（懒惰＝本场战斗中累计打出至少 3 张攻击牌；2026-10-06 改名，id 仍为 `wrath`）**或**撑到第 5 回合（保底）【2026-10-07 紧缩制：8→5】；未解锁前不可摆放/打出（界面置灰＋卡面提示封印原因与进度）
- **一场对局只能出现并使用一次**：打出后本场不会再离开/回来；同种罪卡即使手中还有第二张也被封印
- 解锁状态**每场战斗重新检定**（不随牌组永久携带）
- 玩法定位：罪卡＝「本场的大招」——任务/保底把它推到中后盘，Cost 6 让它独占一回合的资源
- 教程战学不到的：收下懒惰时战斗已结束、当场用不到它；罪卡的解锁/一次限制从第二层起自然展示（蓄意）
- 接线实现（2026-10-05）：收下→局内收藏（`RunState`）→仓库→组卡最多一张；战斗内封印/解锁按**牌组中的罪卡**逐卡检定（任务/保底参数按卡配置；教程战照旧）
- 原型实现：`BattleConfig.SIN_CARD_ID` / `SIN_ROUND_FALLBACK=5`（2026-10-07 紧缩制；原 8）/ `SIN_TASK_ATTACK_PLAYS=3`；`BattleState.turn_count` / `attack_plays_this_battle` / `sin_available` / `sin_used_this_battle` / `_check_sin_unlock` / `_sin_available` / `sin_lock_reason`；`BattleScreen` tooltip 显示封印原因与任务进度；罪卡专属紫色卡框（`frame_sin`）

## 增幅类（弃牌触发加成）【用户定 2026-10-04】

## 卡牌堆叠【用户定 2026-10-04：大类内互叠＋出牌区拖叠＋打进打出结算】

- **堆叠范围：同大类内互叠**——攻击↔攻击（「普通魔弹」可叠「强力魔弹」）、防御↔防御、功能↔功能；跨类不可叠；罪卡/增幅牌/核心牌/敌牌不参与
- **操作**：手牌拖到出牌区**同类已摆牌**上＝合成一张（占**同一卡槽**）；合成牌拖回手牌＝拆回原牌逐张回手
- **费用**：合成牌费用 ＝ Σ原牌费用 ＋ 每多一张收 `STACK_FEE`（1）——合成瞬间可用 Cost 实时减少、打出时按合成牌费用整批扣、拆开收回不花（叠费随合成消失）
- **加成形态：相加**——两张普通魔弹（各 2 伤）合成「造成 4 点伤害」（费用 3）；效果文本自动汇总（按 op 聚合求和）
- **核心价值：堆叠绕过出牌区 4 卡槽上限【2026-10-07 紧缩制：5→4】**——把更多价值压进同一卡槽，代价是多付叠费（空间换资源）
- 结算：合成牌的攻击任务按**原牌张数**计（合两攻击并打出＝累计 2）；打出后弃牌堆里是**原牌**（合成体不粘进牌堆）；合成牌名「普通魔弹＋强力魔弹」形（＋连接）
- 拖叠目标提示：拖拽中悬停可叠牌 → 该牌描金高亮
- 原型实现：`BattleConfig.STACK_FEE`；`BattleState.can_merge_with` / `merge_into_staged` / `_make_merged` / `_parts_of`；`CardData.parts` / `is_merged()`；`signal card_merged`；`CardButton.set_merge_highlight`（描金边框面板 `MergeHighlight` 显隐，测试用 `is_merge_highlighted()`）；拖放命中走 `BattleScreen._merge_target_at` / `_update_merge_hover`（**须过滤 `is_queued_for_deletion()` 的旧子节点——rebuild 残留会造成索引错位**）

## UI 重构：扇形手牌＋计数标签＋全游戏统一【2026-10-03·续 12】
