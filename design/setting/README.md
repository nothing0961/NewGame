## 核心验证问题（防漂移基准）

来自纸原型主持单（2026-10-02）：

> 零解释前提下，玩家能否在打净召唤者那一瞬间自己理解「这不是杀死，是净化；罪得收下，进我的牌组」？

（术语改定 2026-10-04：原引文作「剥离」；正式表述＝打败 boss ＝ 完成净化仪式）

- 保留条件：至少 1 名无提示玩家 8 分钟内主动收下罪卡且有明显反应
- 现阶段刻意不做/不测：战斗平衡、七宗罪后续接线、正式美术
- 单局 5–10 分钟，含三问 ≤ 20 分钟
- 一切改动服务于「净化时刻的重量感」；UI/文案改动优先考虑是否强化这个瞬间
- 配套规则（2026-10-03）：战前一切对话与提示不解释「怎么救」，只把目标说成打倒／清空血量；「净化」「收下」不被提前提及
